ATM Machine
Summary of the Task
The program simulates a basic ATM system where users can:

View account balance
Withdraw money
Deposit money
Enter a PIN for security
Main Features
Initial balance is Rs. 10000
Withdraw function with validation checks
Deposit function with PIN verification
Automatic balance update after transactions
Concepts Used
HTML input fields and buttons
JavaScript functions
Variables and conditions
DOM manipulation
User interaction using prompt() and alert()
